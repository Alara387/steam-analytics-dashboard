# 🎮 Steam Game Analytics Dashboard

This is our Data Visualization course project (Assignment 4).
We built an interactive dashboard to explore Steam game data using R Shiny.

## What it does:
- Filter games by release year, price, and rating.
- See how many games were released each year.
- Explore the most popular genres.
- Check the relationship between price and user ratings.
- Browse individual games and see their details.

## Dataset:
We used the Steam Store Games dataset from Kaggle (~27,000 games).

## Built with:
R, Shiny, Plotly, DT, ggplot2, dplyr
